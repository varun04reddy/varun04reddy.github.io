# Figure captions — Summing Over Training Histories

## fig1-goe-semicircle.png
**Title:** The semicircle appears from random dynamics  
**Caption:** GOE eigenvalue histogram (N=4000) with Wigner semicircle overlay.  
**What to notice:** Microscopic entries are noise; the macroscopic spectrum is deterministic law.

## fig2-response-decay.png
**Title:** The spectrum becomes memory  
**Caption:** R_z(τ) from finite N vs. semicircle theory; τ^{-3/2} reference at late times.  
**What to notice:** Numerical curve tracks theory; slope → −3/2 where edge modes dominate.

## fig3-mode-decay.png
**Title:** Which eigenmodes survive?  
**Caption:** Heatmap W(λ,τ) = ρ(λ) e^{-(λ+z)τ}; marginal R_z(τ).  
**What to notice:** Late-time response concentrates near λ = −2 (spectral edge).

## fig4-correlation-heatmap.png
**Title:** Correlation as a memory surface  
**Caption:** Normalized C(t,t′) for shifted GOE dynamics.  
**What to notice:** Structure follows t + t′; memory fades as both times grow.

## fig5-response-heatmap.png
**Title:** Response as causal memory  
**Caption:** R(t,t′) with triangular (causal) support.  
**What to notice:** Zero below the diagonal — no response before the perturbation.

## fig6-sym-antisym.png
**Title:** Real spectra relax; imaginary spectra oscillate  
**Caption:** Eigenvalues and response for symmetric vs. antisymmetric random M.  
**What to notice:** Real line → decay; imaginary axis → oscillation.

## fig7-linear-regression.png
**Title:** Learning curves as macroscopic observables  
**Caption:** Train (solid) and test (dashed) loss vs. step, colored by α = P/N.  
**What to notice:** Test hits noise floor; train reflects label noise; α changes decay rate.

## gif-spectral-modes-response.gif
**Title:** The spectral edge becomes long memory  
**Caption:** Modes composing R_z(τ) as τ increases.  
**What to notice:** Fast modes vanish; edge modes survive.
